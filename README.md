# Allsets

A full-featured Android quiz app with 40+ question sets across 12 subjects in English and Hindi.

## Icon
![icon](res/mipmap-xhdpi/icon.png)

## Subjects
**English**: Analogy, Biology, Brain Teasers, Chemistry, GK, Odd One Out, One Word, Physics, Science
**Hindi**: Biology, Geography, History, Politics

## Features
- 40+ question sets loaded from JSON assets
- Timer-based quiz with sound effects
- Gold/scoring system with high score tracking
- Online ranking via PHP backend
- Online multiplayer match support
- In-app update checker
- Language selection (English/Hindi)

## Build
Eclipse/ADT project. Min SDK 12, Target SDK 27.
